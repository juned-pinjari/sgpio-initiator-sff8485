# SGPIO Initiator (SFF-8485)

A synthesizable Verilog implementation of an SGPIO (Serial General Purpose Input/Output) Initiator, designed according to the **SFF-8485** specification (Rev 0.7).

## Overview

SGPIO is an interface defined for storage enclosures to manage LED activity and drive status across a serial backplane using a 4-wire bus:

- **SClock**: Serial bus clock generated by the Initiator.
- **SLoad**: Frame sync signal asserted on the last bit of a transmission.
- **SDataOut**: Serial transmit stream (Activity, Locate, Error bits per drive).
- **SDataIn**: Serial receive stream (drive presence / status).

## Project Structure

- `rtl/` — Verilog RTL design files
- `tb/` — Simulation testbenches and verification

## Implementation Details

- Target Specification: SFF-8485 Rev 0.7
- Stream framing: 3 bits per drive (ODn.0 = Activity, ODn.1 = Locate, ODn.2 = Error)
- Frame length: Configurable (minimum 4 drives / 12 bits per spec)
